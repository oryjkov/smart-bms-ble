Install from the browser menu. Chrome hasn't offered a one-tap install here yet, so:

  • Android: tap ⋮ → Add to Home screen (or Install app) → Install.
  • Desktop Chrome/Chromium: ⋮ → Cast, save, and share → Install page as app…, or the install icon at the right end of the address bar.

Close the Daly phone app first — the BMS accepts only one connection.

Requires Chrome or Chromium. On Android, Web Bluetooth works out of the box; only the second flag is needed for auto-connect. On Linux, enable both. Open each flag (copy it into the address bar), set it to Enabled, and restart the browser:

  • chrome://flags/#enable-experimental-web-platform-features — Web Bluetooth itself
  • chrome://flags/#enable-web-bluetooth-new-permissions-backend — remembers the device so the page can auto-connect on load
